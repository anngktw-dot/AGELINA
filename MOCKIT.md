# MockIT — AI-Assisted Recruiting Workflow

**Front-end MVP built for an ideathon**

MockIT is a clickable recruiting workflow prototype designed to bring the main recruiter journey into one product flow—from initial setup to candidate evaluation and reporting.

## Problem

Recruiting workflows are often fragmented across separate tools and manual steps. Recruiters spend time on repetitive candidate screening, inconsistent interview processes, and scattered evaluation notes.

## Solution

MockIT demonstrates a single recruiter workspace with a connected flow:

1. Login
2. Recruiter onboarding
3. Company and hiring setup
4. Dashboard and vacancies
5. Candidate review
6. Resume-analysis UI
7. Live interview workspace
8. Summary report
9. Billing demo

## What the MVP Includes

- connected screen-to-screen flow
- login → onboarding transition
- shared demo state persisted with `localStorage`
- vacancy search/filter interactions
- candidate review path
- editable live-interview response area
- dynamic demo scoring
- lightweight billing interactions
- consistent visual system across screens

## Tech Stack

- HTML
- CSS
- JavaScript
- localStorage

The lean stack was chosen to build and iterate quickly during the ideathon without depending on backend infrastructure.

## Current Project Stage

MockIT is an **interactive front-end MVP**, not a production-ready AI product.

### Already implemented

- full recruiter journey UI
- connected navigation between core screens
- interactive demo behavior
- shared demo state and data passing
- resume-analysis and interview-assistance interfaces

### Not implemented yet

- real backend API
- persistent database
- production authentication
- real AI resume analysis
- real AI interview scoring
- billing engine
