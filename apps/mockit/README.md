# MockIT — AI-Assisted Recruiting Workflow MVP

A reconstructed source version of the front-end MVP we built for the ideathon demo.

## Implemented demo behavior

- recruiter onboarding state stored in `localStorage`
- vacancies search/filtering
- candidate review flow
- resume-analysis demo UI
- live interview response editing
- dynamic demo scoring
- summary report
- billing action demo

## Stack

- HTML
- CSS
- JavaScript
- localStorage

This remains a **front-end demo MVP**. It does not claim to include a real backend, database, production authentication, real AI resume analysis, or a billing engine.

Open `index.html` in a browser to run the demo.
