# Titanic Survival Prediction

A machine-learning classification project based on the Titanic passenger dataset.

## Tech Stack

- Python
- Pandas
- scikit-learn
- Decision Tree classifier
- Matplotlib

## Project Work

The project covered a typical beginner-to-intermediate supervised machine-learning workflow:

- loading and exploring tabular data
- preprocessing and preparing features
- training a classification model
- using a Decision Tree classifier
- evaluating model results
- visualizing selected data / results
- documenting the project through supporting report / presentation materials

## What This Project Demonstrates

- Python for data science
- data preprocessing
- tabular classification
- scikit-learn workflow
- basic model evaluation
- communicating ML results
