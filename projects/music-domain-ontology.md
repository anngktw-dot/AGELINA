# Music Platform Domain Ontology

A semantic-web / knowledge-representation project modeling a music and podcast platform domain.

## Tech Stack

- Python
- RDFLib
- RDF / OWL
- SPARQL
- SHACL

## Project Focus

The project modeled entities and relationships from a Spotify-style music / podcast domain using semantic-web technologies.

Project work included:

- defining domain concepts and relationships
- representing knowledge with RDF / OWL
- querying structured knowledge with SPARQL
- validating graph constraints with SHACL
- using Python and RDFLib to work with the ontology programmatically

## What This Project Demonstrates

- knowledge representation
- graph-based data modeling
- semantic-web technologies
- SPARQL querying
- ontology validation
- Python tooling around RDF data
