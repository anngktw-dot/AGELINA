# Local AI Data Lab

A local desktop data-analysis project for working with spreadsheet and tabular data without depending on a remote cloud workflow.

## Tech Stack

- Python
- PyQt6
- Pandas
- DuckDB
- openpyxl
- pyxlsb
- PyArrow / Parquet

## Project Focus

The application was designed around importing and analyzing local Excel/tabular datasets through a desktop interface.

Project work covered:

- reading spreadsheet data
- local data processing
- working with multiple tabular formats
- dataframe-based transformations with Pandas
- local analytical queries with DuckDB
- Parquet / PyArrow-oriented data handling
- desktop UI integration with PyQt6

## What This Project Demonstrates

- Python desktop development
- practical data processing
- spreadsheet ingestion
- local analytics workflows
- combining GUI code with a data-processing layer
- handling structured data without requiring a hosted backend
