# Offline AI Assistant

A local-first AI chat project designed to run a language model on-device instead of depending on a hosted API.

## Tech Stack

- Flutter
- Dart
- llama.cpp
- llama_cpp_dart
- GGUF models
- Qwen2.5 1.5B

## Project Focus

The assistant was built around a local streaming chat experience with an embedded/offline model workflow.

Project work included:

- loading a local GGUF language model
- integrating llama.cpp through Dart bindings
- streaming generated responses into the chat UI
- building a mobile-style chat interface with Flutter
- keeping inference local rather than sending prompts to a remote AI service

## What This Project Demonstrates

- local LLM integration
- AI application architecture
- Flutter / Dart development
- streaming response handling
- model/runtime integration
- privacy-oriented offline product thinking
