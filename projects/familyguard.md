# FamilyGuard

A family safety / parental-control project built around separate parent and child mobile experiences plus a backend service.

## Project Scope

FamilyGuard was designed to give a parent visibility into a child device through a connected application flow.

Project work included features around:

- parent and child application roles
- device/location monitoring concepts
- application usage visibility
- website/activity monitoring
- screenshot-based monitoring flows
- backend communication between the app sides

## Architecture

The project was structured as a multi-part system rather than a single standalone UI:

- parent application
- child application
- backend service

A working MVP version was developed under the `FamilyGuard_MVP` project work.

## What This Project Demonstrates

- multi-client application thinking
- backend integration
- data flow between devices and services
- product logic for role-based functionality
- debugging and testing of a connected MVP
